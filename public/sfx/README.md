# Sound effects

The B-roll renderer mixes two short effects under the voice:

| File         | Used for                       | Length |
| ------------ | ------------------------------ | ------ |
| `whoosh.wav` | image enters (every B-roll item) | 0.55 s |
| `pop.wav`    | image exits (every B-roll item)  | 0.16 s |

Additional generated effects are available for use elsewhere in the app or in
edits:

| File | Sound | Length |
| --- | --- | ---: |
| `notification.wav` | Two-note notification chime | 0.62 s |
| `camera-shutter.wav` | Short shutter click and mechanism | 0.24 s |
| `swipe.wav` | Brief airy transition sweep | 0.32 s |
| `cash.wav` | Bright rising cash-register-style chime | 0.72 s |
| `correct.wav` | Positive two-note answer cue | 0.48 s |
| `wrong-answer.wav` | Descending low answer cue | 0.42 s |
| `riser.wav` | Rising noise-and-pitch transition | 1.20 s |
| `text-readout.wav` | Short sequence of electronic readout beeps | 0.68 s |
| `camera-flash.wav` | Bright flash snap and decaying tone | 0.18 s |
| `radio.wav` | Short radio static burst | 0.75 s |

## Licence

All files are **generated by this repository** with
`scripts/generate-broll-sfx.mjs` (synthesized tones, envelopes, and deterministic noise)
and are dedicated to the public domain under **CC0 1.0**
(https://creativecommons.org/publicdomain/zero/1.0/). No attribution is
required, and no third-party sound library is involved.

Regenerate them with:

```bash
node scripts/generate-broll-sfx.mjs
```

The B-roll effects are mixed at ~0.28 gain by `lib/broll/sfx.ts`, below speech, with FFmpeg's
`amix … normalize=0` so the speaker's level never changes. B-roll sound effects
can be switched off per video ("B-roll → Sound effects" in the pipeline options).
