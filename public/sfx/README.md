# B-roll sound effects

Two short effects are mixed under the voice when B-roll appears:

| File         | Used for                       | Length |
| ------------ | ------------------------------ | ------ |
| `whoosh.wav` | image enters (every B-roll item) | 0.55 s |
| `pop.wav`    | image exits (every B-roll item)  | 0.16 s |

## Licence

Both files are **generated by this repository** with
`scripts/generate-broll-sfx.mjs` (band-limited noise sweep and a decaying sine)
and are dedicated to the public domain under **CC0 1.0**
(https://creativecommons.org/publicdomain/zero/1.0/). No attribution is
required, and no third-party sound library is involved.

Regenerate them with:

```bash
node scripts/generate-broll-sfx.mjs
```

They are mixed at ~0.28 gain by `lib/broll/sfx.ts`, below speech, with FFmpeg's
`amix … normalize=0` so the speaker's level never changes. B-roll sound effects
can be switched off per video ("B-roll → Sound effects" in the pipeline options).
